
### 🛒 Street Market – Front-End Web Project

A fully static web project that showcases a local **street market platform**, where users can explore products, learn about the team, find location details, and interact through sign-up and sign-in pages. Built with HTML, CSS, and JavaScript, this project is ideal for portfolio presentation or as a UI prototype for future development.

## 🌟 Key Features

- 🏠 **Landing Page (`index.html`)** – Clean homepage with navigation to key sections  
- 📦 **Products Page (`product.html`)** – Display of market items (static demo layout)  
- 👥 **Our Team Page (`Our_Team.html`)** – Info about the development team or staff  
- 📍 **Location Page (`location.html`)** – Includes information about market location  
- 🔐 **User Pages** – `signin.html` and `signup.html` simulate authentication interfaces  
- 📞 **Contact Page (`contact.html`)** – Simple contact form layout

## 🚀 Getting Started

To run the project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/Street-Market.git
   cd Street-Market
   ```

2. **Open `index.html`** in your browser (double-click or use a local server like Live Server in VS Code)

3. **Explore other pages** by navigating via buttons or manually opening the files
